## 4つの特徴（アーロンの考え方）

心理学者のエレイン・アーロンは、繊細な人の特徴を4つにまとめている（DOES）。
・D 深く考える（Depth of processing）
・O 刺激を受け取りやすい（Overstimulation）
・E 気持ちを感じ取りやすい、共感しやすい（Emotional reactivity, Empathy）
・S 小さな変化に気づく（Sensitivity to subtleties）

## あるある20とやさしい言い換え

深く考える
・返事の前に、いろいろ考える → ていねいに言葉を選んでいる
・寝る前に、今日の会話を思い出す → 人との時間を大切にしている
・決める前に、たくさん比べる → よく考えてから選べる
・本や映画の余韻が、ずっと残る → ひとつのことを深く味わえる
・「なぜ？」が気になる → ものごとの奥を見ようとしている

刺激を受け取りやすい
・人混みのあとは、ひとりになりたい → たくさん受け取った分、休む時間が必要
・音や光、においにすぐ気づく → まわりの変化を感じ取れる
・予定が続くと、ぐったりする → 余白があると、力を出せる
・急な予定の変更で、どきっとする → 準備を大切にできる
・せかされると、頭が真っ白になる → 自分のペースだと、力を出せる

気持ちを感じ取りやすい
・人の表情の変化に、すぐ気づく → 人の気持ちに寄り添える
・映画やニュースで、涙が出る → 心が動く
・誰かが注意されていると、自分までどきっとする → 人の気持ちを、自分のことのように感じられる
・頼まれると、断りにくい → 相手を大切にしている
・褒められると、うれしいけど照れる → 受け取ったものを大切にしている

小さな変化に気づく
・模様替えや髪型の変化に、すぐ気づく → 人をよく見ている
・季節のにおいがわかる → 季節の移り変わりを楽しめる
・服のタグや素材が気になる → 心地よさを大切にしている
・声のトーンで、気持ちがわかる → 言葉の奥まで聞き取れる
・小さな幸せを、深く感じる → いちばんの宝物
