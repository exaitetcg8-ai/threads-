## 月50万円の逆算

報酬単価で、必要な件数が全然変わる。

・報酬1件10,000円 → 月50件
・報酬1件5,000円 → 月100件
・商品価格5,000〜10,000円で報酬率30% → 報酬1,500〜3,000円 → 月167〜333件

月100件を、LINE登録から購入3%で売るなら
月に約3,300人のLINE登録が必要。

フォロワー0からの現実ラインはこう。
・3ヶ月：初報酬（月1〜3万）
・6ヶ月：月10〜15万
・9〜12ヶ月：月30〜50万

ここを早めたいなら、報酬単価を上げるか
いずれ自分の商品を足すのが近道。

## 自動化のレベル

・1ヶ月目：Lv1（予約投稿だけ）
・2ヶ月目〜：Lv2（AIで下書きを作り、自分で直して予約）
・Lv3以上（投稿を丸ごとツールに任せる）は、売れてから検討

Xは自動投稿や同じ内容の連投に厳しい。
・APIキーを人に共有しない
・連投しすぎない（1日1〜3投稿）
・投稿前に必ず自分の目で確認する
・Xの規約変更をチェックする

ツールの仕様や料金は変わりやすいので、使う前に最新情報を確認してね。

## このジャンルで絶対に守ること

・不安や恐怖で買わせない（悪いことが起きる、このままだと不幸になる、は書かない）
・霊感や運気を理由に高額な購入をすすめない
