## 月50万円の逆算

報酬単価で、必要な件数が全然変わる。

・報酬1件10,000円 → 月50件
・報酬1件5,000円 → 月100件
・商品価格5,000〜10,000円で報酬率30% → 報酬1,500〜3,000円 → 月167〜333件

月100件を、LINE登録から購入3%で売るなら
月に約3,300人のLINE登録が必要。

フォロワー0からの現実ラインはこう。
・3ヶ月：初報酬（月1〜3万）
・6ヶ月：月10〜15万
・9〜12ヶ月：月30〜50万

ここを早めたいなら、報酬単価を上げるか
いずれ自分の商品を足すのが近道。

## 自動化のレベル

・1ヶ月目：Lv1（予約投稿だけ）
・2ヶ月目〜：Lv2（AIで下書きを作り、自分で直して予約）
・Lv3以上（投稿を丸ごとツールに任せる）は、売れてから検討

Xは自動投稿や同じ内容の連投に厳しい。
・APIキーを人に共有しない
・連投しすぎない（1日1〜3投稿）
・投稿前に必ず自分の目で確認する
・Xの規約変更をチェックする

ツールの仕様や料金は変わりやすいので、使う前に最新情報を確認してね。

## このジャンルで絶対に守ること

・不安や恐怖で買わせない（悪いことが起きる、このままだと不幸になる、は書かない）
・霊感や運気を理由に高額な購入をすすめない
・「治る」「必ず叶う」「運気が上がる」と断定しない
・医療の代わりではないと、PDFとLINEで伝える
・紹介するメッセージには【PR】【広告】を明記する
・ASPの規約で、LINEでの紹介が許可された案件だけを使う
・自分で試していない商品は紹介しない

## 紹介する講座の選び方

候補になる講座の種類（整う、のコンセプトに合うもの）
・瞑想、マインドフルネスのオンライン講座
・ヨガ、ピラティス、ストレッチのオンラインレッスン
・アロマ、ハーブ、カラーセラピーなどの通信講座（資格系）
・タロット、占星術、数秘術を自分で学ぶ講座
・手帳、ジャーナリング、習慣化の講座
・心理学、セルフコーチング系のオンライン講座

報酬の目安（必ずASPの案件ページで確認）
・講座価格5,000〜10,000円だと、報酬は数百〜数千円になりやすい
・1件5,000〜10,000円の報酬は、数万円の講座か
　無料体験、無料説明会の申込みで成果になる案件に多い

選ぶ時のチェック6つ
・ASPの規約で、LINE公式での紹介が許可されている
・自分で受講、体験してから紹介できる
・運営会社、返金条件、問い合わせ先が公式ページに書いてある
・公式ページ自体が誇大な表現をしていない
・承認率（成果が確定する割合）が書いてあって、低すぎない
・からだ×心を整える方向の内容で、投稿30本の流れと合う

紹介しないもの
・開運、霊視、除霊など、霊感を理由に高額を払わせるもの
・人生が必ず変わる、など断定で売っているもの
・申込み後に、さらに高額な契約へ誘導される評判があるもの

## Threadsとの並行（週11時間）

2つのアカウントは、別の人格として分ける。
・Threads：繊細さん、論文ベース、自分の商品（21日間ワーク）
・X：整うスピリチュアル、アフィリエイト
・資格はXでも出さない。スピの紹介と資格を結びつけない
・LINE公式も2つ。混ぜると、どちらの教育も弱くなる

時間配分
平日1時間
・15分：両方の投稿をストックから予約
・20分：コメント、リプ周り（Threads10分、X10分）
・15分：両方のコメント、LINEの返信
・10分：伸びた投稿を1行メモ

休日3時間
・60分：Threadsの投稿7本
・45分：Xの投稿7本（Threadsで伸びたテーマを、スピの言葉に置き換える）
・45分：LINE、PDF、講座選び
・30分：両方の数字を見て、来週の型を決める

ネタは使い回す。作るのは1回、言い方を2通りにする。

## ロードマップ（X側）

Phase A：土台構築（1ヶ月目）
┗ プロフィールを作り、No.01を固定

┗ 30本の数字から伸びた型を3つに絞る

┗ 体験した講座で、LINEのDay2とDay5〜7を書く
┗ 数値目標：フォロワー300人、LINE登録30人

┗ ステップ配信をフル稼働
┗ Day0の返信と、購入しなかった理由を原文で集める
┗ 数値目標：LINE登録60人、初報酬1〜3件

Phase D：拡大（4〜12ヶ月目）
┗ 売れた講座の周辺で2本目の案件を追加
┗ Xの投稿を1日2本へ
┗ 数値目標：6ヶ月で月3〜5万、12ヶ月で月10〜20万
