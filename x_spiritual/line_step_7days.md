# LINE 7日間ステップ配信｜整うスピリチュアル

導線
X投稿 → プロフィールのリンク → LINE登録 → 無料PDF自動送信 → 7日間ステップ → アフィリエイト商品の案内

教育の順番（この順を崩さない）
・Day0：受け取り、返信のきっかけ
・Day1：目的（こうなりたい）
・Day2：信用（この人なら信じられる）
・Day3：問題点（なぜ今のままだと続かないのか）
・Day4：手段（整える順番）
・Day5：投資＋商品の紹介
・Day6：買わない理由6つを先に解消
・Day7：行動（最後の案内）

配信設定の目安
・Day0：登録直後に自動送信（あいさつメッセージ）
・Day1〜7：毎日20時30分
・【】はあなたの情報と、選んだ商品の情報に差し替える

アフィリエイトで必ず守ること
・ASPの案件ページで、LINE公式やメルマガでの紹介が許可されているか確認する
　（許可されていない案件は、この導線では使えない）
・商品を紹介するメッセージには【PR】または【広告】と明記する（ステマ規制）
・紹介する商品は、自分で買って試したものだけにする
・独自特典をつける場合は、案件の規約で特典が認められているか確認する
・締切は本物だけ。キャンペーン期限がない商品で、期限を作らない
・不安や恐怖で買わせない。悪いことが起きる、などの表現は絶対に使わない

運用メモ
・リッチメニューは「無料PDF」「おすすめ」「相談」の3つ
・返信は24時間以内。Day0の返信は原文のまま保存して投稿ネタにする
