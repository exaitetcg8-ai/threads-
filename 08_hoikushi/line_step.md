# LINE｜特典と5日間ステップ

写真のロードマップの⑤⑥。

導線
Threads/X → プロフィールのリンク → LINE登録 → 特典を自動送信 → 5日間で記事を1本ずつ → Day4で転職サイトの記事

特典（LINE登録の特典。転職サービス登録の見返りにはしない）
「ホワイト保育園の見分け方チェックリスト」
・Googleドキュメントか画像でOK。スマホで見やすいこと優先

配信設定の目安
・Day0：登録直後
・Day1〜5：毎日21時（保育士さんが家事を終えて、スマホを見る時間帯）
・Day5のあと：月2回、働き方や転職時期の記事

運用メモ
・リッチメニュー：「チェックリスト」「記事一覧」「相談する」の3つ
・Day0の質問への返信を原文で保存して、投稿ネタにする（投稿に使う時は本人の許可を取る）
・返信は24時間以内に
・つらさが強い返信が来たら、転職の話はせず、相談窓口や医療機関をすすめる


## 特典の中身｜ホワイト保育園の見分け方チェックリスト

### 1. 求人票で見る
□ 年間休日の日数が書いてある
□ 有休の取得実績が書いてある
□ 残業代の扱いがはっきりしている（固定残業代が含まれていないか）
□ 持ち帰り仕事についての記載がある
□ 行事の数や内容がわかる
□ ICT（登降園管理、連絡帳アプリ、書類のデジタル化など）の記載がある
□ 処遇改善の手当が、給与の内訳に書いてある

### 2. 見学で見る
□ 職員さんの表情が明るい
□ 職員同士の会話がやわらかい（指示が怒鳴り口調じゃない）
□ 掲示物や制作物が、手作りにこだわりすぎていない
□ 子どもへの声かけが落ち着いている
□ 休憩室や職員の休憩時間の話が出る

### 3. 面接で聞いていい質問
□ 持ち帰り仕事はありますか
□ 行事の準備は、勤務時間内にできますか
□ 有休はどのように取っていますか
□ 職員の方は、何年くらい働いている方が多いですか
□ 書類や連絡帳は、手書きですか、アプリですか

### 4. 今の園と比べる
□ 上の項目で、今の園に当てはまるものに印をつけた
□ ゆずれない条件を3つ書き出した

※このチェックリストは一般的な目安です。最終的には見学や面接で、ご自身の目で確かめてください。
