## 提携申請の前に確認すること

1. 成果条件（「初回登録」は何をした時点か。電話面談まで必要か）
2. 否認条件（保育士資格なし、重複登録、連絡がつかない、など）
3. 掲載できる媒体（Threads、X、note、LINE）
4. 禁止表現、使っていいサービス名やロゴ
5. 特典の上乗せ禁止（「登録したらプレゼント」はNG）

LINEのプレゼントは、LINE登録の特典として配る。
転職サービスへの登録の見返りにはしない。

A8にThreads/Xアカウントをサイトとして登録しておく。
申請前に、保育士向けの投稿を10〜20本出しておくと審査が通りやすい。

## あなたの立ち位置

保育士として働いた経験がない前提で組んでいる。

・「元保育士」「わたしも転職して」とは絶対に書かない
・「保育士さんの悩みと転職情報をまとめる人」として出る
・公認心理師などの資格は出さない
・体験談が必要なところは、アンケートやリプでもらった声を、本人の許可を取って使う
・投稿や記事の【】は、自分で確認した事実に差し替える

もし保育士の経験があるなら、教えてもらえれば当事者目線で書き直す（そのほうが強い）。

## ロードマップ

Phase A：準備（1〜2週目）
┗ 新アカウントを作る（名前に「保育士」を必ず入れる）
┗ プロフィールを決める（下にあり）
┗ posts.md を1日3本で出し始める
┗ 保育士アカウントに、毎日リプ5〜10件（その人の投稿を読んでから）
┗ A8にアカウントを登録 → プログラム詳細を読む → 提携申請
┗ 数値目標：投稿20本、フォロワー100人

Phase B：記事とLINE（3〜4週目）
┗ articles.md の記事をnote（またはブログ）に公開
┗ LINE公式を開設、line_step.md の特典と5日間ステップをセット
┗ 提携が通ったら、Day4の記事にA8のリンクを入れる
┗ 数値目標：フォロワー300人、LINE登録20人

Phase C：回す（2〜3ヶ月目）
┗ 投稿を1日3〜5本へ。伸びた型を3つに絞って量産
┗ LINEの返信で「今どの段階か」（モヤモヤ中／辞めたい／転職先を探し中）を集める
┗ 返信の多い悩みで記事を追加（月2本）
┗ 数値目標：フォロワー1,000人、LINE登録100人、初成果

Phase D：広げる（4ヶ月目〜）
┗ 自分のクリック数と成果数から「LINE登録何人で1件」を出し、目標を決め直す
┗ 同じ保育士の読者向けに、別の転職サービスを比較記事で足す（1人が複数登録するのは自然）
┗ 数値目標：LINE登録300人、成果が毎月出る状態

## 法律と規約の注意

広告表記（ステマ規制）
・アフィリエイトリンクがある投稿、記事、LINEには毎回【PR】
・記事の冒頭に「この記事には広告（アフィリエイトリンク）が含まれています」

書いてはいけない表現
・「必ず年収が上がる」「絶対ホワイト園に入れる」「誰でも内定」
・特定の園や法人を名指しで悪く書く
・給料や求人の数字を盛る（使うなら出典と時点を書く）
・体験談を作る

退職の話をする時
・法律や就業規則の話は「一般的には」と書き、最終的には就業規則の確認や専門窓口の相談をすすめる
・心身がつらそうなリプには、転職サイトではなく、相談窓口や医療機関をすすめる（ここで売らない）
