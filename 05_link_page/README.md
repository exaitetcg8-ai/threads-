# リンク先ページ（X・Threadsプロフィールのリンク）

流れ
X・Threadsプロフィールのリンク → このページ → LINE友だち追加 → あいさつメッセージでPDFが届く

ファイル
・index.html：ページ本体（スマホ向け）
・cover.png：PDFの表紙画像
・og.png：リンクを貼った時に出る画像（1200×630）

## 公開までの5ステップ

1. LINE公式アカウントを作る
　・アカウント名はXと同じ（もの || 優しい世界を届ける）にする
　・アイコンもXと同じ空の画像にする

2. 友だち追加URLをコピーする
　・管理画面の「友だちを増やす」から、友だち追加URL（lin.ee/から始まるもの）をコピー

3. index.htmlの1か所だけ書き換える
　・ファイルの一番下の LINE_URL = の右側を、コピーしたURLに置き換える
　・ボタン2つとも、自動でそのURLになる

4. ページを公開する
　・このフォルダ（index.html、cover.png、og.png）をそのままアップロードする
　・静的なHTMLを無料で置けるホスティングサービスで公開できる
　・サービスの仕様や無料枠は変わりやすいので、使う前に最新情報を確認する
　・公開できたら、index.htmlの og:image と og:url を公開先の絶対URLに書き換えて、もう一度アップロードする

5. XとThreadsのプロフィールのウェブサイト欄にリンクを貼る
　・スマホで一度タップして、LINEが開くところまで確認する

## LINE側の設定

・あいさつメッセージ：03_line_step/line_step_7days.md のDay0を貼る
　PDFのURL（GoogleドライブなどでリンクURLを知っている人は閲覧可にしたもの）を入れる
・ステップ配信：Day1〜Day7を、友だち追加の翌日から1日1通で設定
・リッチメニュー、応答メッセージ、ステップ配信：03_line_step/richmenu_and_delivery.md

## 先に確認しておくこと

・LINE公式アカウントは、無料プランだと月に送れるメッセージ数に上限がある
・ステップ配信も通数に数えられる。登録者が増えると無料枠を超えやすい
　（例：月40人の登録 × 7通 ＝ 280通）
・プランと上限は変わるので、開設時に公式の料金ページで確認する

## 公開がすぐできない時

ページの公開に手間取るなら、最初の数日はXとThreadsのプロフィールに
LINEの友だち追加URLを直接貼ってもOK。
ページは公開できた時点で差し替える。
