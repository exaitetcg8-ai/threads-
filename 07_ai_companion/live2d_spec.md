# りん Live2Dモデル 制作仕様書（依頼用）

`studio.html` のモデルは、ブラウザで動く簡易版（SVG）です。
配信ソフト（VTube Studio など）で使う本格的なLive2Dモデルにするときは、この仕様書をイラストレーターさんとモデラーさんに渡してください。
パラメータ名と動きは簡易版とそろえてあるので、簡易版を「完成イメージの動く見本」として見せられます。

## 1. キャラクター

・名前：りん（20歳、148cm）
・髪：銀白のロング。毛先に水色〜ラベンダーのグラデーション。前髪はぱっつん寄りで毛束が細かい。アホ毛1本
・目：青紫。ハイライト多め、下側に明るい反射
・ヘアアクセ：右側に白い5枚花＋水色リボン（たれ2本）、クロスしたヘアクリップ2本。左に小さな白い花
・衣装（基本）：白いもこもこニット、オフショルダー、水色のキャミ肩ひも、胸元に小さな水色リボン
・雰囲気：やわらかい、にこにこ、甘め。白×水色×ペリウィンクル

| ふわふわコート | 冬服 | 任意 |

## 3. パーツ分け（イラスト側：PSD）

・目：白目／瞳（左右別）／ハイライト／上まつげ／下まつげ／二重線／閉じ目（笑顔の閉じ目も）
・まゆ（左右別）
・口：上唇／下唇／口の中／舌／歯（上）
・顔：輪郭／ほお（赤らみ・斜線の差分）／鼻
・髪：前髪（毛束ごとに3〜6分割）／横髪（左右）／後ろ髪（2〜3分割）／アホ毛
・アクセ：花、リボンのたれ、ヘアクリップ（揺れもの用に分ける）
・体：首／体／腕（左右、袖口つき）／衣装パーツ
・差分：ねこみみ、うさみみ、フード、ツインテール、ヘッドホン
・各パーツの見えない部分（髪の下の頭、まぶたの下など）も描いておく

## 4. パラメータ（モデラー側）

簡易版の名前 → Live2D標準パラメータ

| 簡易版 | Live2D | 範囲 | 動き |
|---|---|---|---|
| angleX | ParamAngleX | -30〜30 | 顔の左右 |
| angleY | ParamAngleY | -30〜30 | 顔の上下 |
| angleZ | ParamAngleZ | -30〜30 | 顔のかたむき |
| bodyX | ParamBodyAngleX | -10〜10 | 体の左右 |
| breath | ParamBreath | 0〜1 | 呼吸 |
| eyeL / eyeR | ParamEyeLOpen / ParamEyeROpen | 0〜1.2 | 目の開閉（1.2はびっくり） |
| eyeSmile | ParamEyeLSmile / ParamEyeRSmile | 0〜1 | 笑い目 |
| ballX / ballY | ParamEyeBallX / ParamEyeBallY | -1〜1 | 目線 |
| brow | ParamBrowLY / ParamBrowRY | -1〜1 | まゆの上下 |
| worry | ParamBrowLForm / ParamBrowRForm | -1〜1 | 困りまゆ |
| mouthOpen | ParamMouthOpenY | 0〜1 | 口の開き |
| mouthForm | ParamMouthForm | -1〜1 | 口の形（への字〜笑顔） |
| cheek | ParamCheek | 0〜1 | ほおの赤らみ |

追加でほしいもの
・揺れもの（物理演算）：前髪、横髪、後ろ髪、アホ毛、リボンのたれ、ツインテール、うさみみ
・表情：にこっ、にっこり、ウインク、ふつう、おだやか、てれ、びっくり、しょんぼり、ねむい（簡易版の数字キー1〜9と同じ）
・待機モーション：ゆらゆら、まばたき
・角度：XYともに±30、できればXYの組み合わせ（9点）まで

## 5. 納品物

・`.moc3`、`.model3.json`、テクスチャ、`.physics3.json`、表情（`.exp3.json`）、モーション（`.motion3.json`）
・VTube Studioで動くことの確認
・元データ（PSD、cmo3）

## 6. 依頼の前に決めること

・使い道：個人の配信／アプリ内／商用（グッズや有料アプリ）。商用の場合は料金と規約が変わる
・クレジット表記の有無
・Live2D Cubism の利用規約（売上規模によって出版許諾が必要になる場合がある）。依頼前に公式サイトで最新の条件を確認する
・元のイラストの権利：依頼先に渡す立ち絵は、自分が権利を持っているか、使用許可があるものにする

## 7. 簡易版との関係

・`js/character.js` の `M.chara.setTrack({...})` に上の表の値を入れると、簡易版のりんが同じように動きます
・本格版ができたら、アプリ内のりん（`#chara`）を pixi-live2d-display などで表示する形に差しかえられます
