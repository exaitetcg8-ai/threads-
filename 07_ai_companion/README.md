# りんのへや｜繊細さんのためのメンタル最適化AIコンパニオン

テーマ：心地よく、自分らしく、自由に

ブラウザで動くWebアプリです。インストール不要、サーバー不要、記録は端末の中だけ。

## 使い方

・`index.html` をブラウザで開くだけで動きます
・スマホで使う場合は、GitHub Pages や Netlify などに `07_ai_companion` フォルダをそのまま置いて公開
・声（女性ボイス）は「へや・設定」→「声」でONにする

## 機能

### 1. おしゃべり（チャットモード）
・入力した言葉から気持ちを読みとって返事をする（疲れ、不安、落ちこみ、さみしさ、イライラ、眠り、いっぱいいっぱい、人間関係、自分を責める、仕事・学校、刺激、体の不調、うれしい、できた、ありがとう、あいさつ）
・返事は「受けとめ → 寄りそい → ふつうのことだよ → 小さなヒント → むすび」の部品を組み合わせて作る。**約175万通り**（画面に通り数を表示）
・3つの話し方：ふつうに話す／ただ聞いてほしい（アドバイスなし）／ヒントがほしい
・返事のあとに、合いそうな5分ワークを提案
・同じ言葉が続かないよう、直近に使った言葉を避ける

### 2. 会話モード（ガイドつき）
りんと一緒に、テーマにそって気持ちを整理する8つの会話。
・朝のチェックイン（心の天気、体調、今日のちいさな目標 → やることリストへ）
・夜のふりかえり（よかったこと3つ、自分へのねぎらい）
・もやもや整理（出来事・気持ち・考え・別の見方。認知行動療法の考え方）
・不安のとなりに（できること／できないことの仕分け、心配する時間の予約）
・セルフ・コンパッション（やさしい3ステップ）
・心の境界線（やさしい断りフレーズづくり → メモへ）
・刺激のふりかえり
・おやすみ前のおしゃべり

### 3. 5分ワーク（提案・実践・ほめる）
・30種類。呼吸、体、今ここ、気持ち、整えるの5分類（21日間ワークと同じ考え方）
・**提案**：日付・時間帯・最近の気分から「今日のワーク」を1つ提案。「ちがうのにする」「今日はやめておく」も選べる
・**実践**：手順を1つずつ表示＆読み上げ。呼吸ワークは光の輪が4秒で大きく、6秒で小さくなる。一時停止、次へ、途中でおわるもOK
・**ほめる**：終わったら2,700通りのほめ言葉。途中でやめても責めずにほめる。スタンプと気分の記録

### 4. 作業支援モード
参考：『Chill with You : Lo-Fi Story』（集中ツールとキャラクターの物語を組み合わせたゲーム）
・ポモドーロタイマー（集中／休憩／長い休憩、時間は自由に設定、4つのプリセット、自動で次へ、チャイム）
・集中中はりんが机でノートを書きながら一緒に作業し、ときどき小さく声をかける（頻度は「話しかけない」も選べる）
・休憩になると、ほめて、休み方（伸び、水分、目を休める）を提案
・やることリスト（終わるとほめる）、メモ（自動保存）
・lo-fi音楽 6曲（その場で作曲・演奏するので著作権の心配なし。ドラムなしの静かな曲もある）
・環境音 12種（雨、川、波、暖炉、風、カフェ、小鳥、夜の虫、風鈴、時計、キーボード、ページをめくる音）を音量つきで重ねられる＋7つのプリセット
・景色：時間帯（現在時刻に連動 or 手動）と天気（はれ、くもり、雨、雪、星空）
・へやの色6種、家具・小物11種、りんの服6種
・なかよし度：一緒にすごすほど上がる（集中1分＝1、5分ワーク＝10、会話モード＝5）。レベルで家具・服・へやの色・ものがたりがひらく
・ものがたり全13話（ヘアピンの思い出、カフェ、ねこ、ステージで歌った日など、りんのことが少しずつわかる）
・ミニ表示：対応ブラウザ（Chrome系）では小さな別ウィンドウにタイマーを表示。それ以外は画面をタイマーとキャラだけにする
・集中ビュー：パネルを隠して部屋とキャラだけにする
・タブのタイトルに残り時間、時間になったら通知（設定でON）
・きろく：今日の集中、累計、ポモドーロ数、7日間グラフ、ワークのスタンプ、心の天気

### 5. 繊細さんへの配慮（決して煽らない）
・連続日数（ストリーク）は出さない。「いっしょにすごした日」の合計だけ
・「やらなかった」「サボった」などの言葉を使わない。やめる、休む、とばすを常に選べる
・音はすべて自分で鳴らしたときだけ。音量は小さめから
・動きを少なくする、文字を大きくする設定
・危ないサイン（死にたい、消えたい等）を見つけたら、相談窓口（いのちの電話、よりそいホットライン、こころの健康相談統一ダイヤル、119）を表示
・会話はすべて端末の中で処理。外部に送信しない

## 言葉を増やす・直す

・おしゃべりの言葉は `js/dialogue-data.js`。各リストに1行足すだけで組み合わせが増える
・5分ワークは `js/works.js` の `W`。`steps` は［表示する文, 秒数］
・ものがたりは `js/story.js` の `EP`

## 今後できること

・**Live2Dモデル**：本格的なVTuberモデルにする場合は、イラストレーターとLive2Dモデラーに依頼して、`#chara` の中身を差しかえる（pixi-live2d-display などで表示）
・**声**：今は端末の音声合成。声優さんの録音や、商用利用できる音声合成（キャラクター音声）に差しかえると、よりりんらしい声になる
・**AIの自由会話**：Claude APIなどにつなぐ場合は、APIキーをブラウザに置かず、小さなサーバー（Cloudflare Workersなど）を経由する。危ないサインの対応は今と同じく必ず残す
・**スマホアプリ化**：PWA化（ホーム画面に追加、オフライン対応）
