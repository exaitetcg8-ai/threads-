# 水音みおのへや（AIコンパニオン）

繊細さん向けのメンタル最適化アプリです。テーマは「心地よく、自分らしく、自由に」。
`index.html` をブラウザで開くだけで動きます（インストール、サーバー、APIキーは不要）。

## ファイル

・index.html：アプリ本体（ドット絵ゲーム風。キャラクター、会話、ワーク、ポモドーロ）
・character_sheet.md：キャラ設定書（Live2D発注用の指定、口調ルール、AI接続用プロンプト）

## できること

おはなし
・気分、元気の量、話題、してほしいこと、時間帯、長さ、距離感の7軸で、103,680通りの会話モード
・自由に書いた文から気分と話題を読みとって、モードを自動で合わせる（端末内だけで処理）
・「死にたい」「消えたい」などの言葉には、提案をやめて相談窓口を表示

今日のワーク
・5〜10分のワーク30種類（呼吸、ボディスキャン、音、セルフ・コンパッション、3行メモなど）
・日付と会話モードから1つ提案。「いっしょにやる」で手順を時間つきでガイド
・やった日は水滴で表示。連続記録は数えない

作業モード
・ポモドーロタイマー（15/5、25/5、50/10）。ドットの水そうに水がたまっていく表示。4回ごとに長めの休憩
・休憩のヒント、やさしいチャイム、「今日はここまで」ボタン
・今日やりたいことは3つまで

そのほか
・水の音（ブラウザで生成する環境音）
・ライト／ダーク表示、動きを減らす設定に対応

## 煽らないための設計

・「がんばれ」「今すぐ」「絶対」「必ず」「治る」は使わない
・連続記録、ランキング、達成率を出さない
・どのボタンも押さなくていいことを、画面の言葉で伝える
・医療の代わりではないことを「このへやのこと」に明記

## 次にやるなら

1. character_sheet.md をイラストレーター、Live2Dモデラーに渡して本番モデルを発注
2. 発注したモデルは Live2D Cubism SDK for Web で `#avatar` の位置に差し替え
3. 生成AIにつなぐ場合は、APIキーをサーバー側に置き、character_sheet.md の7章をシステムプロンプトに使う
