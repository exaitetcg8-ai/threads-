## 週11時間の使い方

平日（1時間）
・15分：その日の投稿を確認して予約（ストックから）
・20分：HSPや繊細さん系の投稿に、自分の言葉でコメント5件
・15分：自分の投稿へのコメント返信、LINEの返信

休日（3時間）
・90分：翌週分の投稿を7本まとめて作る
・45分：LINE、PDF、商品まわりの作業
