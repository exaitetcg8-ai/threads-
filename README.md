## 導線の全体像

Threads（毎日1投稿）
┗ プロフィールのリンク
┗ LINE登録（無料PDFを自動送信）
┗ 7日間ステップ（目的→信用→問題点→手段→投資→行動→締切）
┗ 21日間ワーク（先行4,980円 → 通常9,800円）
┗ 個別セッション付きプラン、月額コミュニティ（売れてから作る）

## ロードマップ（Phase 0想定）

【あなたの現在地（仮定）】
・フェーズ：Phase 0〜1
・強み：悩みが毎日起きるジャンル、論文ベースという差別化軸
・課題：フォロワー、リスト、実績がまだゼロ

【ゴール】
・3ヶ月後：月10万円
・12ヶ月後：月100万円

Phase A：土台構築（〜1ヶ月目）
┗ プロフィールとコンセプトを確定（No.01を固定投稿に）
┗ 30本を1日1投稿、21時前後に投稿
┗ LINE公式を開設、Day0〜7の自動配信をセット
┗ 予約投稿機能を使って投稿作業を週1回にまとめる
┗ 数値目標：フォロワー300人、LINE登録30人

Phase B：集客基盤（〜2ヶ月目）
┗ 30本の数字を見て、伸びた型を3つに絞る
┗ LINEのDay0の返信（悩みの原文）を100個集める
┗ 集めた言葉で、言い当てる1行目を作り直す
┗ 1日2投稿へ（AIで下書きを作り、必ず自分で手直し）
┗ 数値目標：フォロワー1,000人、LINE登録100人

Phase C：収益化（〜3ヶ月目）
┗ 21日間ワークを先行モニター4,980円で10〜20名募集
┗ 修了者の感想を集める（掲載許可は必ず取る）
┗ 感想をもとに通常価格9,800円で再販
┗ 数値目標：月10万円（9,800円×10件前後）

Phase D：拡大（〜6ヶ月目以降）
┗ 個別セッション付きプラン（29,800円前後）を追加
┗ 修了者向け月額コミュニティを開設
┗ 数値目標：6ヶ月で月30万円、12ヶ月で月100万円

【今週やることTOP3】
1. Threadsのプロフィールを作り、No.01を投稿して固定する
2. LINE公式を開設し、Day0のメッセージとPDFをセットする

毎日の投稿が仕組みで回っていて、
LINEに30人、悩みの生の声が30個たまっている状態。

【注意点・落とし穴】
・論文の数字を盛らない。「治る」「必ず」は使わない
・医療の代わりではないと、PDF、LINE、商品の3か所で伝える

・フォロワー数だけを見ない。LINE登録数と返信内容を見る

## 投稿について

Threadsへの自動投稿は、このリポジトリからは行っていません。
アカウント連携とAPIキーが必要になるので、
予約投稿機能のあるツールにposts_30.mdを貼り付けて使ってください。
ツールの仕様や料金は変わりやすいので、使う前に最新情報を確認してね。

投稿前の4ルール
・APIキーを人に共有しない
・連投しすぎない（1日1〜2投稿）
・投稿前に必ず自分の目で確認する
・Threadsの規約変更をチェックする
