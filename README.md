## 月100万の内訳（時間が少ない人向けの形）

平日1時間の人が個別セッションを増やすと
時間が先に尽きる。
だから1対1ではなく、1対多で組む。

・21日間ワーク 9,800円 × 月30件 ＝ 約29万円
・心のチューニング 伴走プラン 29,800円 × 月15件 ＝ 約45万円
　（21日間ワーク＋休日に月2回のオンライン少人数会）
・心のチューニングルーム 2,980円 × 100人 ＝ 約30万円
・合計 約104万円

いきなりここは狙わない。

アフィリエイトはこの内訳に入れていない。

## 週11時間の使い方

平日（1時間）
・15分：その日の投稿を確認して予約（ストックから）

・10分：伸びた投稿、伸びなかった投稿を1行でメモ

休日（3時間）
・90分：翌週分の投稿を7本まとめて作る
・45分：LINE、PDF、商品まわりの作業

ポイントはこれ。

作るのは休日にまとめる。
