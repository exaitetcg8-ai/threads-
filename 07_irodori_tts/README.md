# Irodori-TTS（日本語の読み上げAI）Windows 導入セット

対象：Windows 10/11 ＋ NVIDIA の GPU

## 入れ方（初回だけ）

1. このフォルダ（07_irodori_tts）を PC にダウンロード
2. `install.bat` をダブルクリック
3. 黒い画面が進むのを待つ（初回は数GBダウンロードするので10〜30分）
4. 最後に「インストールが完了しました」という音声が流れたら完了

本体は `C:\Users\（ユーザー名）\Irodori-TTS` に入ります。
Git と uv が入っていなければ、自動で入れます。
もう一度実行すると最新版に更新されます。

## 使い方

| やりたいこと | ダブルクリックするもの |
|---|---|
| 普通に読み上げる／声をまねる（参照音声） | `start.bat` |
| 「落ち着いた女性の声」など文章で声を作る | `start_voicedesign.bat` |

起動するとブラウザが自動で開きます（モデルの読み込みに少し時間がかかります）。
終わるときは黒い画面を閉じます。

## うまくいかないとき

- 「NVIDIA のドライバが見つかりません」「GPU が見えません」
  → https://www.nvidia.co.jp/drivers から最新のドライバを入れて、install.bat をもう一度
  （GTX 10 シリーズ以前の古い GPU は、今の PyTorch では動かないことがあります）
- 「実行してよいか」の警告が出る
  → 「詳細情報」→「実行」
- メモリ不足のエラー
  → GPU のメモリが少ない場合は、軽量版モデル `Aratako/Irodori-TTS-v4.1-Small-Quantized/int8-weight-only` を使う
