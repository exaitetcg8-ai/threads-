# 特典9｜境界線の言い換え辞典 20

人との間で
1. 断れない → 相手を大切にしたい
2. 顔色をうかがう → 安全を確かめている
3. 機嫌をとってしまう → 場を守ろうとしている
4. 先回りしてしまう → 人の変化に気づける
5. 合わせてしまう → 場を大切にできる
6. 本音が言えない → 言う時を選んでいる
7. 流されやすい → 人の気持ちに寄りそえる
8. 頼まれると引き受ける → やさしさが先に動く

自分の反応について
9. 固まってしまう → 体が守ろうとしている
10. 人前で声が出ない → 緊張から、身を守っている
11. あとからどっと疲れる → がんばったぶん、体が休みを求めている
12. 気をつかいすぎる → 人を大切にできる
13. 罪悪感がわく → まわりを大切にしたいしるし

これからの言葉
14. 断ったら嫌われる → 無理なく続く関係のほうが長く続く
15. 我慢しなきゃ → これは、わたしが選んだこと？
16. 全部わかってほしい → 自分で自分をわかっていれば大丈夫
17. すぐ返事しなきゃ → 少し考えてから、お返事しますね
18. わたしのせいかも → これは、あの人の気持ち
19. 期待に応えなきゃ → 応えられる時に、応えればいい
20. 休んでいいのかな → 休む予定も、大切な予定
