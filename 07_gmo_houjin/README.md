## 最初に結論

・この案件は、HSPアカウントには絶対に載せない
　読者が違う。HSPの読者に銀行口座を出すと、信頼だけ削れて1件も売れない
　→ 別アカウント「一人社長・法人成り」ジャンルで回す

・法人口座が必要な人は「法人を作った人」「これから作る人」だけ
　看護師（数十万人）より母数がずっと小さい
　だから、フォロワー数より「設立直前の人」を集める精度が勝負

・SNSで「口座作って」とは言わない
　Threads/Xは集める場所、記事とLINEで教える、記事の中で自然に紹介する
　写真のロードマップと同じ形で、ここだけは崩さない

## 提携申請の前に確認する5つ

A8のプログラム詳細で必ず見る。ここを読まずに投稿を作ると、全部やり直しになる。

1. 報酬額と成果条件（口座開設完了で成果か、入金や取引まで必要か）
2. 否認条件（既存顧客、自己アフィ、短期解約など）
3. 掲載できる媒体（Threads、X、note、LINEへの掲載がOKか）
4. 禁止表現（「最安」「必ず審査に通る」など、金融系は厳しめのことが多い）
5. 特典の上乗せ禁止（口座開設した人にプレゼント、はほぼ確実にNG）

5は特に大事。
写真の⑤「プレゼント企画」は、LINE登録の特典として配る。
口座開設の見返りとして配るのはNG。ここを混ぜない。

A8にはThreads/Xアカウントを「サイト」として登録しておく（審査で見られる）。
提携審査の前に、ジャンルに合った投稿を10〜20本出しておくと通りやすい。

## あなたの立ち位置（大事）

体験があるかないかで、書き方を変える。

体験がある場合（自分で法人を持っている）
・「一人社長の実体験」として書く。一番強い
・GMOあおぞらを実際に使っているなら、使っている画面や困った点まで書く

体験がない場合
・「法人成りを調べ尽くしてまとめる人」として出る
・「わたしも使っています」「開設しました」は絶対に書かない（作り話は信頼と規約の両方を壊す）
・その代わり、公式情報・比較・口コミの傾向を丁寧にまとめる
・自分が法人化を準備しているなら、その過程をそのまま発信するのはアリ

投稿・記事の【】は、自分の事実に差し替えてから使う。

## ロードマップ

Phase A：準備（1〜2週目）
┗ 新アカウントを作る（名前に「法人成り」「一人社長」など検索される言葉を入れる）
┗ プロフィール文を決める（下にあり）
┗ posts.md の集客投稿を1日3本で出し始める
┗ 法人成り・起業系アカウントに、毎日リプ5〜10件
┗ A8にアカウントを登録 → プログラム詳細を読む → 提携申請
┗ 数値目標：投稿20本、フォロワー50人

Phase B：記事とLINE（3〜4週目）
┗ articles.md の3本をnote（またはブログ）に公開
┗ LINE公式を開設、line_step.md の特典と5日間ステップをセット
┗ 提携が通ったら、Day4の記事にA8のリンクを入れる
┗ 数値目標：フォロワー200人、LINE登録10人

Phase C：回す（2〜3ヶ月目）
┗ 投稿を1日3〜5本へ。伸びた型を3つに絞って量産
┗ LINEの返信で「今どの段階か」（迷い中／設立準備／設立済み）を集める
┗ 返信の多い悩みで記事を追加（月2本）
┗ 数値目標：フォロワー500〜1,000人、LINE登録50人、初成果

Phase D：広げる（4ヶ月目〜）
┗ 法人化まわりの別案件（会計ソフト、設立代行、法人カード）を、記事ごとに1つずつ追加
┗ 1人のLINE登録者から、設立の流れに沿って複数の成果が出る形にする
┗ 数値目標：LINE登録200人、成果が毎月出る状態

成果の数字は、報酬額・成果条件・あなたの投稿量で大きく変わるので
ここではあえて金額を置いていない。
提携後に報酬額を見て、「LINE登録何人で1件」を自分の数字で測ってから目標を決める。

## 法律と規約の注意（金融系は特に厳しい）

広告表記（ステマ規制）
・アフィリエイトリンクがある投稿、記事、LINEには毎回【PR】を最初に書く
・記事の冒頭には「この記事には広告（アフィリエイトリンク）が含まれています」

数字と条件
・手数料、キャッシュバック率、開設日数は、条件つきのことが多い
　バナーの「最短即日」「他行宛100円」「通常1.0%キャッシュバック」も条件つき
・数字を書く時は、条件と「◯年◯月時点」を必ずセットにする
・投稿前に、公式サイトの最新の条件を確認する（変わる）

書いてはいけない表現
・「審査に必ず通る」「誰でも作れる」「最安」「一番お得」
・他の銀行を名指しで下げる書き方
・税金の話で「これで節税できる」と断定（人によって違う。税理士に相談、と添える）

特典
・LINE登録の特典はOK
・「口座開設したら◯◯プレゼント」はNG（A8の規約違反で報酬が取り消される）
