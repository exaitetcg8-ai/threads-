# 光の姫の旅路（作業支援ゲーム）

雨と雲に覆われた中世ファンタジーの世界で、優しいお姫様リュシアが「自分の応援で世界を癒す」旅に出ます。
プレイヤーが作業している間に、姫は世界を回って人々を応援し、魔物から守ります。作業時間が長いほど、世界に色が戻っていきます。

## 遊び方

`index.html` をブラウザで開くだけで動きます（インストール不要）。データはブラウザに自動保存されます。

1. 「タスク」でやることを登録する
2. 「冒険」でタスクを選び、タイマーの「はじめる」を押す
3. 作業中、姫が自動で旅を進める（魔物の討伐、人々の応援、装備や服装の入手）
4. 作業時間と実績で物語が1話ずつ解放される（全50話）

## 機能一覧

| 機能 | 内容 |
|---|---|
| ポモドーロタイマー | 作業・小休憩・長休憩。時間、長休憩までの回数、休憩の自動開始、終了音を設定で変更できる |
| タスク | 期限、見積もり回数、実際の作業回数を記録。取り組み中のタスクに作業回数が加算される |
| 日程管理表 | 週表示（月曜始まり）。予定、タスクの期限、その日の作業時間が並ぶ |
| 記録 | 起動回数、総作業時間、完了回数、1回の平均と最長、連続日数、直近14日のグラフ、1回ごとの作業ログ |
| 世界の彩り | 物語の進み具合（65%）と累計作業時間（35%、50時間で最大）で彩度が上がる。雨と雲も減る |
| 討伐の演出 | 魔物を倒すと一瞬光が差し、約9秒間雨が止む |
| 物語 全50話 | 10地域×5話。物語ポイント（作業30分＝1pt、実績1つ＝1pt）で順番に解放 |
| 衣装室 | 服装30種、装備30種、髪型12種、髪色10色。物語・実績・冒険の戦利品で増える |
| ハクスラ要素 | 装備はN/R/SR/SSR。同じ装備を拾うと重なって強化（+1ごとに能力+10%） |
| ステータス | 攻撃力と応援力は作業時間でレベルが上がる。攻撃力は討伐しやすさ、応援力は人々からの感謝に影響 |
| 会話 | 「話しかける」でN/R/SR/URのセリフ（全70種）。累計作業時間と今の作業の長さでレア確率が上がる |
| 実績 | 39種。物語ポイントにもなる |
| エンドコンテンツ | 第50話を読むと世界が光に包まれ、「常闇の底」に降りられる。階層は無限で、深いほど敵が強く、装備強化の上限もなくなる |

## ファイル

- `index.html`：画面
- `style.css`：見た目
- `data.js`：物語・セリフ・装備・服装・実績のデータ（文章の差し替えはここ）
- `game.js`：ゲームの処理
- `build_artifact.py`：4ファイルを1つのHTMLにまとめるスクリプト（`python3 build_artifact.py 出力先.html`）

## データの引っ越し

設定 →「書き出す」で出た文字列をコピーし、別の端末で貼り付けて「読み込む」。
